## 🎯 Estrutura Padrão dos Documentos
Cada arquivo contém rigorosamente:
1. **Descrição Geral**: O que é a funcionalidade e seu objetivo central.
2. **Como Utilizar**: Tutorial prático com comandos e exemplos de diálogos em linguagem natural no WhatsApp.
3. **O que Consegue Fazer**: Recursos homologados, formatos aceitos e capacidades ativas.
4. **O que NÃO Consegue Fazer**: Limitações técnicas, salvaguardas de segurança e restrições operacionais.
